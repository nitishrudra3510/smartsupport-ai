# SmartSupport AI — Full-Stack Customer Support & Developer Assistance Platform

SmartSupport AI is a full-stack web application designed to streamline customer support workflows through ticket management and AI-assisted troubleshooting.

## Key Features

- **Ticket Management:** Create, assign, prioritize, track, and resolve support tickets.
- **Role-Based Access:** Separate customer, support agent, and administrator permissions.
- **AI Assistance:** Generate ticket classifications, conversation summaries, and suggested replies using an LLM.
- **RAG Knowledge Assistant:** Retrieve relevant FAQ and documentation content and provide answers with source references.
- **Developer Assistance:** Summarize technical errors and suggest documentation-based troubleshooting steps.
- **Testing & Deployment:** Automated tests, Docker containerization, and CI/CD integration.

## Tech Stack

- Frontend: React, Vite, TypeScript
- Backend: Python, FastAPI
- Database: PostgreSQL, pgvector
- AI: Large Language Models (LLMs), Retrieval-Augmented Generation (RAG)
- DevOps: Docker, GitHub Actions, Coolify
